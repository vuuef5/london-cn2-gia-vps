## 伦敦这条线是怎么走的，200ms 到底什么感觉

按第三方测评的实际路由记录，伦敦机房的分运营商走向是这样的：电信去程和回程都走 CN2/CTG GIA；联通回程强制走 CN2 GIA，去程走 10099；移动去程和回程都走 CMIN2。这和官方宣传里“三网回程 CN2 GIA”的说法基本对得上，但不要理解成“三网去回程全是 CN2 GIA”，联通和移动的去程并不是。

延迟方面，伦敦约 200ms，圣何塞约 168ms，法兰克福约 180ms。伦敦是三个机房里最慢的一个，原因很简单，物理距离摆在那儿。

200ms 意味着什么？单次请求往返 0.2 秒。网页首屏加载要靠并发和缓存摊薄，实际体感没有那么夸张，但 SSH 敲命令、后台点按钮这类交互，能感觉到比圣何塞慢一拍。作为对照，普通欧洲 VPS 的延迟普遍在 230ms 左右，伦敦这个数字在英区机器里还算体面。

吞吐上有一点要提前说清楚。套餐标的是 500Mbps 端口带宽，第三方实测里本地单线程 TCP 打不满这个峰值，回中国的 TCP 单线程大约在 100Mbps 上下。做网站、传文件、跑常规服务够用，但别把 500Mbps 当成“单线程下载能跑满 500Mbps”。同一次测评里记录的下载峰值约 60Mbps、上传约 20Mbps，母鸡负载不高，硬盘 I/O 表现不错，丢包率低。

还有一个必须点明的限制：**伦敦不在流媒体解锁名单里**。官方和测评只提到法兰克福支持 Netflix 解锁、圣何塞部分套餐有原生 IP，伦敦没有被列进去。冲着看英区流媒体去的，先别把它当解锁机。

## 下单前必须确认的四件事

**一、不保证原生 IP，且不能因此退款。** 官方说明里写得很直接：分配到的 IP 不保证是原生 IP，也不保证和测试 IP 同网段。如果你的项目强依赖原生 IP（比如某些账号注册、特定平台风控），下单前必须自己确认，事后拿这个理由退款走不通。

**二、只支持支付宝。** 国内用户付款方便，但如果你习惯用信用卡、PayPal 或者加密货币，这里没有选项。

**三、客服不是 24 小时。** 工作时间是每天 12:00 到 22:00，工作时间内提交的工单承诺 24 小时内答复、48 小时内解决。另有一个 Telegram 交流群可以问问题。凌晨出事只能等第二天中午。

**四、换 IP 是要钱的。** 按第三方整理的信息，新开通的机器如果 IP 已被墙，可以提工单免费换一次；圣何塞每月免费换一次，超出按 30 元/个收费，德国按 15 元/个。伦敦的换 IP 收费标准在公开资料里没写，买之前建议直接问客服。
